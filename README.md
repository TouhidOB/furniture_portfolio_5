# furniture_portfolio_5

> **MONO OBJECTS** — The Art of Less.

A museum-grade collectible furniture gallery platform featuring interactive 3D inspection, multi-axis rotation, exploded engineering visualization, side-by-side object comparison, and acoustic material exploration.

## 🚀 Key Features
- **Museum-Grade Curation**: One-piece-at-a-time focus with disciplined editorial typography
- **Interactive Exploded View**: Deconstruct objects into raw timber, foam core, and upholstery layers
- **Side-by-Side Comparison Studio**: Compare silhouettes, specs, and materials in real time
- **Production HTML & Bundle**: Pre-compiled production build included in `dist/`

## 🛠 Tech Stack
- **React 18** + **Vite**
- **Three.js** / **@react-three/fiber** / **@react-three/drei**
- **GSAP** Smooth Scrub Animations
- **Tailwind CSS**

## 💻 Quick Start
```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
